# ほくほく！おちばあつめでやきいも (261123-2)

## 起動方法
- `index.html` を開くだけ（file:// でも Pages のサブフォルダでも可。外部読み込みなし、約 2.1MB）。
- 作り直すとき: `node tools/build.mjs`（`src/` と `assets/` を1ファイルにまとめる。esbuild が必要。`--assets` で画像を再埋め込み）。

## 遊びの流れ
くまでで落ち葉を石の輪へ集める → かごのおいもを山に入れる → ライターで火をつける → うちわであおぐ →
火ばさみで灰からざるへ → 手で割って（黄・紫・オレンジ）食べる → 風でまた落ち葉が降って次の回へ。
小さな発見: 木をさわると葉が降る／どんぐりが火ではぜる／あおぎすぎると煙／最後の1枚が山に落ちる／2回目から大きいおいも。

## 確認したこと（390×844、ヘッドレス Chromium）
- 読み込み・開始時のコンソールエラーなし。
- 合成したポインター操作で、掃く→食べる→2回目の掃き始めまで1回通した（エラー0）。
- 各場面で、次に触る物が光・揺れで示され、放置で指のお手本が出ることを画面で確認。
- 再読み込みで保存した場面（灰から取り出す場面）に戻ること。
- 横画面 1180×820 は最初の画面とうちわの場面だけ目視。

## 描画パフォーマンス（iPhone / iPad 向け）
- 起動時に全シェーダーをコンパイルし全テクスチャを GPU へ送っておく（火・灰・割ったおいもが初めて出る瞬間のカクつき対策）。
- 焚き火の光は消えている間も明るさ0で残す（光の数が変わると全マテリアルが再コンパイルされるため）。
- 描画ピクセル数の上限 約320万: スマホは2倍のまま、大きい iPad は約1.5倍で描く。
- 自動画質調整は画面のリフレッシュ間隔（60/120Hz、低電力モードの30Hz）を基準に判定し、
  影の解像度 2048→1024 → 解像度を段階的に下げる → 影なし、の順で落とす（速くなれば解像度は戻す）。

## 既知の問題
- 実機（iPhone / iPad の Safari）では未確認。音はすべて合成で、耳での確認はしていない。
- 掃く・あおぐ手ざわりはヘッドレスのコマ送りでしか見ていない（実時間の操作感は未確認）。
- くまでと落ち葉は石をすり抜ける。割ったおいもの断面は画面上ではやや小さい。
- 夕方の遠景で、背景写真の上端に空の帯が見えることがある。
- `?step` を付けると自己確認用の早送り関数（`G.devStep`）が有効になる（通常の遊びには影響なし）。
