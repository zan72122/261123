# ごしごし！うわばきあらってほそう（261123-3 / gf-261123-nx3）

文字なし・指1本の 3D ゲーム。真っ黒な上履きを袋から引っぱり出し、蛇口を回してたらいに水をため、
ブラシでごしごし → 黒い水をざばーっと流してすすぎ → 手回し脱水機をくるくる → 物干しに干す →
夕焼け・夜・朝 → 真っ白になった上履きを袋へ。袋をさわると「また まっくろ」でもう一周。

## 起動方法
- `index.html` をそのまま開く（file:// でも Pages のサブフォルダでも可。外部読み込みなし、1ファイル完結）。
- 作り直すとき: `npm install` のあと `node build.mjs`（`src/` を three.js ごと `index.html` に埋め込む）。
  `node build.mjs --dev --out x.html` は開発用で、`?stage=<id>`（bag, fill, dunk, scrub, rinse, load, spin, hang, sun, pack, end）
  でその場面から、`?fresh` で保存を消して開始できる。

## 中身
- `src/engine/` 起動・カメラ合わせ・1本指入力・段階ヒント（光 → 揺れと音 → 半透明の指のお手本）・保存。
- `src/world.js` 庭と空と時間帯、`shoes.js` `bag.js` `washprops.js` `dryprops.js` 小道具、`fx.js` 水・泡・ほこり、`audio.js` 音（すべて合成）。
- `src/common.js` 状態・水道と水のシミュレーション・くつを運ぶ操作、`scenes_wash.js` `scenes_dry.js` 各場面。
- 画像・音はすべて実行時に手続き生成（外部素材なし）。保存は localStorage（30分以内なら続きから。拒否・破損時は最初から）。

## 描画パフォーマンス（iPhone / iPad 向け）
- 描画解像度: dpr は 2 まで、さらに描画バッファ全体を 2.6MP までに制限（大きい iPad でも大型 iPhone 程度の画素数）。
  フレームが 60fps に届かないとすぐ少し下げ、余裕があればゆっくり戻す（直前に重かった解像度へはしばらく戻らない）。
  30fps に張り付く場合（低電力モード）は 0.7 倍までしか下げない。
- 最初の数フレームで全マテリアルのシェーダーと全テクスチャを先に用意し、場面が変わった瞬間のカクつきをなくした。
- 影マップは毎フレーム描かず、影を落とす物体・光源が動いたときだけ描き直す（ゆっくりした揺れは1フレームおき）。
- 1つのマテリアルを通常メッシュとインスタンスメッシュで共有していた箇所を分け、影パス用の深度マテリアルも分けた（毎描画のシェーダー再判定をなくした）。
- こすり場面のヒント位置探索を累積和テーブルにして約8倍速く（結果は同じ）。
- 見た目は場面ごとのスクリーンショット比較で変化なし（ヘッドレスで、同じ時間内のフレーム数は約2倍）。

## 起動の速さ（初回表示）
- 最初の場面（袋の場面）に映るもの（テラス・光・袋・くつ・たらい・水しぶき類）だけを最初のフレームまでに作り、
  蛇口・ブラシ・せっけん・脱水機・物干し・物干しばさみと、庭（芝・草・家の壁・生け垣・遠くの木と家・空）は
  表示後に1フレーム1つずつ裏で作る（指が画面にふれている間は休む）。場面が変わる前には必ず全部そろう
  （残っていればその場で作る）。続きから別の場面で始まるときは従来どおり最初に全部作る。
- シェーダーの準備（全マテリアルのコンパイルとテクスチャ転送）を、表示直後の一括処理から、毎フレーム少しずつに変更。
  発行したプログラムは次のフレームで使用開始するので、ドライバの裏側コンパイルを待たずに済む。
- 最初のフレームで用意するシェーダーは 76 → 24 個。ヘッドレス Chromium（ソフトウェア描画）で最初の表示まで約 9.6 秒 → 約 5.5 秒。
- WebGL 非対応時の埋め込み静止画は、表示するときだけデコードする。
- 各場面のスクリーンショットを変更前と比較し、見た目は同じ（差はアニメーションの時刻ずれ程度）。

## 確認したこと（390×844、ヘッドレス Chromium）
- 読み込み・開始時にコンソールエラーなし。
- 袋 → おしまい → もう一周の先頭まで、実際のポインタ操作で1回通して遊び、止まる場面がないこと。
- 各場面で、放置すると次の1操作（引く・回す・運ぶ・こする・傾ける・くるくる・はずす）を半透明の指が実演すること。

## 既知の問題
- 実機（iPhone / iPad）では未確認。音は耳で確認できていない（合成結果の機械的な確認のみ）。
- ヘッドレス環境は 1fps 前後のため、ブラシやクランクの手ざわりの速度感は実機での調整が必要かもしれない。
- 干す場面は脱水機と物干しの距離があり、洗濯ばさみがやや小さく映る。
- WebGL が使えない端末では埋め込みの静止画だけを表示する。
