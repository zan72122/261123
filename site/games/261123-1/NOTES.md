# ういーん！でんどうドリルで ほんだなづくり（261123-1 / gf-261123-nx1）

- 起動: `index.html` をそのまま開く（file:// でも Pages のサブフォルダでも可。外部読み込みなし）。
- 作り直し: `src/` を編集して `python3 build.py`（three.js r160・engine・props・audio・game を 1 ファイルにインライン化）。
- お話: ぐらぐらの本の塔が崩れる → 板をならべる → ドリルでねじ6本 → ひっくり返してもう6本（途中で電池切れ→交換）→ 本棚を立てる → 本をしまう → ランプを点けて夕方 → 空き箱でもう一度。
- 確認したこと: 390×844 のヘッドレス Chromium で、起動時コンソールエラーなし、実ポインタ操作で最初から最後まで 1 回通し、各段階で次の 1 操作が光・揺れ・構図で示されること。
- 既知の問題: 実機（iPhone / iPad）での音量バランス・フレームレート・マルチタッチは未確認。ヒントの光は淡い色の板では控えめに見える。
- 描画の軽量化: 影マップは影を落とす物・太陽が動いた時だけ描き直す（engine.js の shadow cache。静止中のドローコールが約1/3に）。描画画素数は約320万までに制限（大きい iPad 向け）。重い端末で低画質モードに入ると影マップも 1024 に下げる。起動時にテクスチャ転送とシェーダー準備を済ませ、初登場時のカクつきを防ぐ。
- 起動の速さ: 床・壁・木口・木目・フェルトの大きな手続きテクスチャは、最初は平均色の小さな見本で描き、本当の模様は Web Worker（OffscreenCanvas。使えない端末では本体側で数ミリ秒ずつ）で裏描きして同じテクスチャに差し替える（出来上がりの画素は従来と同一）。夕方の環境光は裏で作るか必要になった時に作る。シェーダーとテクスチャの事前転送は最初の1枚を出した後に回し、画面はその1枚目から 0.35 秒でふわっと表示する。ヘッドレス計測で最初の1枚まで約 1.3 秒 → 約 0.6 秒。
